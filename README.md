# ESP32-Smart-Watch
Analog and digital clock display.

Real-time temperature, humidity and weather updates.

Interactive web-based control panel.

Modern Liquid Glass UI with smooth animations.

Stopwatch with start, stop and reset controls.

Customizable countdown timer.

12-hour and 24-hour time formats.

City-based weather and timezone configuration.

EEPROM-based storage for city and display mode.

Responsive mobile and desktop interface.
